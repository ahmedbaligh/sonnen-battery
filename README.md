# Sonnen Battery

## Overview

This is a simple dashboard web application that displays charging states of a Sonnen Battery. It uses mocked Sonnen API data to simulate the battery state of charge. Two views are available: a battery UI view where data is grouped by charge level, and a table view where data is displayed in a table format.

## Installation

1. Clone the repository

```bash
git clone https://github.com/ahmedbaligh/sonnen-battery.git
```

2. Install dependencies

```bash
yarn
```

3. Start the application

```bash
yarn dev
```

4. Open the application in your browser at `http://localhost:5173`.
